# `Sources/JavaIntelligence/Maven`

Loaded when working under `Sources/JavaIntelligence/Maven`. Moved out of `Sources/JavaIntelligence/CLAUDE.md`.

- **Maven** (`Sources/JavaIntelligence/Maven/`, `Testing/MavenTestRunner.swift`, `Coverage/MavenCoverageArguments.swift`, `Diagnostics/MavenProblemMatcher.swift`). `MavenProjectReader.read` builds a reactor from `pom.xml` on disk: parents, BOMs and dependencies come from the local repository, `XMLParser.shouldResolveExternalEntities` stays false, and no Maven process runs. `MavenProjectModel.javaProjectModel` projects that reactor into a `JavaGradleProjectModel` (`GradleProjectModelScript.formatVersion`, now 9, `gradleVersion` `"maven"`) so indexing, `javac`, runtime classpaths and coverage scope stay on the Gradle-shaped model. A module path is `:` or `:` plus the relative directory with `:` between folders. Each module has `main` and `test` source sets and a test task `<path>:test` whose results directory is `target/surefire-reports`. `MavenVersion` orders versions the way Maven does (`1.0-SNAPSHOT` < `1.0` < `1.0-sp1`, including a qualifier glued to its number). `MavenReadOptions.disabledProfiles` keeps a profile off even when the POM would activate it. `MavenCommandRunner` runs goals only for a trusted root (`mvnw`, then a settings override, then `mvn` on `PATH`) through `SystemGradleProcessLauncher`. `MavenDependencyDownload` asks Maven for artifacts that are not in the local repository. `MavenTestRunner` builds `mvn test` with `-pl` / `-am` and a Surefire debug agent. `MavenCoverageArguments` injects a JaCoCo or JFR agent, and refuses when Surefire's `argLine` omits `@{argLine}`. `MavenProblemMatcher` turns Maven's `javac` lines into the same problems Gradle's matcher does; Maven's column is 1-based. Run configurations add `.mavenGoals` and `.mavenTest`. Tests: `MavenProjectReaderTests`, `MavenToolingTests`.

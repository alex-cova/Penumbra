# `Sources/JavaIntelligence/Libraries`

Loaded when working under `Sources/JavaIntelligence/Libraries`. Moved out of `Sources/JavaIntelligence/CLAUDE.md`.

- **External libraries** (`Sources/JavaIntelligence/Libraries/`). Pure values for the Explorer's External Libraries section. `JavaLibraryCoordinates.parse(jar:)` reads group, artifact, version and classifier off a Gradle cache path (`modules-2/files-2.1/<group>/<artifact>/<version>/<hash>/<file>`) or a Maven repository path, anything else is `.local` (labelled by file name). `JavaExternalLibrary.list(from:)` is the deduplicated union of every source set's compile and runtime jars (not annotation processors), sorted by label. `JavaArchiveContents.nodes(entries:layout:)` builds the tree from central-directory names alone: flat dotted packages with their top-level types, resource-only folders, root resources; inner classes (`$`), `module-info`, `package-info` and `META-INF/versions/` are left out; `.moduleRooted` takes a JDK `src.zip` (or module-prefixed jmod names) and puts a module level on top. `JavaAttachedSources.extractResource` copies a non-class entry under `attached-sources/` so it opens read-only. `Document.isDependencySource` (path under `attached-sources`, or a server-generated Swift interface, `DependencySourceLocation`) marks such a file: `JavaCompilerDiagnosticsService.compilableURL`, `JavaInspectionService`, `JavaSyntaxAwareDiagnostics` and `JavaCodeActionProvider` all skip it, so a dependency is navigated, never analysed. Tests: `JavaExternalLibrariesTests`, `JavaInspectionServiceTests`, `JavaCompilerDiagnosticsServiceTests`.

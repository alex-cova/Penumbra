# Bookmarks (`Umbra/Sources/Umbra/Bookmarks`)

Loaded when working under `Umbra/Sources/Umbra/Bookmarks`. IntelliJ's bookmarks: a line of a file to get back to, anonymous or named by a mnemonic (`1`–`9`, `0`, `A`–`Z`), kept in lists.

- **`IDEBookmarkStore`** is pure (Foundation and `FileChangeStamp` only). One instance per app (`IDESharedServices.bookmarks`), one JSON file (`Application Support/com.umbra.editor/bookmarks.json`) holding a snapshot per project root: `lists`, `defaultListID`, `bookmarks`. Every call reloads the file when it changed on disk, so a second window is not overwritten. A project always has a list (the first, named after the folder; its id is derived from the project key so reading a project that stored nothing yet names the same list each time); deleting a list deletes its bookmarks, but never the last list. A mnemonic names one bookmark per project: giving it to another takes it from the first, which `setMnemonic` returns. Next/Previous walk bookmarks by file path, then line, wrapping. `moveLines(in:to:removing:)` is how an edit's line moves reach the store; it writes only when something changed.
- **The gutter** is Penumbra's `GutterBookmark` layer (`Sources/Penumbra/CLAUDE.md` ▸ Navigation), set per pane in `IDEWorkspace.applyBookmarkGutter(to:document:)` from the place a document is presented in a pane (next to the change stripe), so every file kind gets bookmarks whatever else owns its gutter. A click removes the bookmark; ⌥-click edits its description.
- **`IDEWorkspace+Bookmarks`**: Toggle Bookmark, Toggle Bookmark with Mnemonic… (a palette list of the 36 characters, each saying whether it is free or moves from another line), Show Bookmarks… (palette list), Next/Previous, Go to Mnemonic (the Navigate ▸ Bookmarks menu lists the named ones; under the IntelliJ preset ⌃1 … ⌃0 go to a digit mnemonic through `IDESecondaryShortcutMonitor`, only when a bookmark has it). The Bookmarks sidebar tab (`IDEBookmarksPanel`, `IDESidebarTab.bookmarks`, order 35) groups by list, previews the line, takes drags between lists and has context menus for description, mnemonic, move and delete.
- **Keys** (`IDEMenuShortcuts`): Sublime and Default use ⌘F2 / F2 / ⇧F2 / ⇧⌘F2; IntelliJ uses F3, ⌥F3, ⌘F3 and ⌃⌥↓ / ⌃⌥↑. Under IntelliJ F3 is therefore not Toggle Line Breakpoint any more: that is ⌘F8, as in IntelliJ.
- Tests: `IDEBookmarkStoreTests`, `GutterBookmarkTests`, `IDEMenuShortcutsTests`.

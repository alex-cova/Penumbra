# Diff viewer (`Umbra/Sources/Umbra/Diff`)

Loaded when working under `Umbra/Sources/Umbra/Diff`. Split out of `Umbra/CLAUDE.md`.

- **Diff viewer** (`Umbra/Sources/Umbra/Diff/`, `IDEWorkspace+Diff.swift`), after IntelliJ's Differences viewer. Diffs open as editor tabs: a `WorkbenchDocument` with `contentKind == .diff` (never restored with the session) whose `IDEDiffSession` lives in `IDEWorkspace.diffSessions`; the pane host lays `IDEDiffViewerView` over its editor while the tab is selected (`showDiffDocument`). An `IDEDiffRequest` names two `IDEDiffSource`s (a `GitRevision` of a path, the working tree, or fixed text). Entry points: double-click (or Show Diff) in the Changes list — unstaged rows compare index ↔ working tree, staged rows HEAD ↔ index, and Previous/Next File walk the rows of that section; the ↗ button over the sidebar preview; History's changed-files list under a commit (parent ↔ commit); Git ▸ Show Diff with HEAD / Compare with Branch / Compare with Clipboard, and the editor's context menu. The model is pure and tested (`IDEDiffComputer`: line LCS with whitespace policies none/trim/ignore/ignore + empty lines, then word, character or split highlighting inside changed blocks; `IDEDiffUnifiedLayout`; `IDEDiffPatchBuilder`). Two Penumbra `TextView`s show the sides with syntax colors (`TextView.lineBackgrounds` for the bands, `highlightedRanges` for words), `IDEDiffDividerView` draws the ribbons, the » chevron (left lines replace the right ones, ⌥-click appends; one undo step) and, for index comparisons, Stage / Unstage of one hunk (`git apply --cached --unidiff-zero`). Unified mode is one read-only text with old/new numbers in the annotation column. Toolbar: ⇧F7/F7 previous/next change (past the last change F7 moves to the next file), Previous/Next File, Jump to Source (F4), layout, whitespace and highlight menus, Collapse Unchanged Fragments (a `foldingProviderOverride` folding all but 3 lines around each change) and Synchronize Scrolling (viewport middles mapped through the chunks). The working-tree side is editable unless its editor tab has unsaved changes; edits are saved on ⌘S, when the tab is left or closed, and before switching files, then clean editor tabs reload. Every git refresh reloads open diffs; one whose texts did not change keeps its place. Options persist in `UserDefaults` (`umbra.diff.*`). Not done: three-way merge, aligned (padded) side-by-side, Compare Previous/Next File keys (⌃⌥←/→ belong to the terminal tabs). Tests: `IDEDiffComputerTests`, `IDEDiffPatchBuilderTests` (patches applied with real git), `IDEDiffTabTests`.

# `Umbra/Sources/Umbra/Agent/Composer`

Loaded when working under `Umbra/Sources/Umbra/Agent/Composer`. Moved out of `Umbra/Sources/Umbra/Agent/CLAUDE.md`.

- **Agent: banners over the composer** (`Composer/IDEAgentBanners.swift`; plan: `docs/AGENT_UI_PLAN.md` items 2 and 6). `IDEAgentBannerLane` sits above the status line in `IDEAgentComposerView` and shows one banner at a time (all share `IDEAgentBanner`: icon, title, one line of detail, buttons on the same row or below when narrow; announced to VoiceOver when it appears). *Decision bar* first: when the chat waits on the user (`IDEAgentConversation.pendingDecision`, the first entry with `isWaitingForUser`) and that card is **not on screen**, an approval gets Show · Deny · Run/Apply (⌘↩; Edit…, a deny note and Always… stay on the card, which Show scrolls to), a question gets Answer… and a plan Review…, both of which scroll to the card. Whether the card is on screen comes from its row (`onScrollVisibilityChange` at 30%, plus `onDisappear`, because a lazy row that is dropped reports no change; `IDEAgentPanel.pendingVisibility`); a card that never reported within 300 ms (its row was never built) counts as hidden. Show sets the panel's `scrollTarget`, which `IDEAgentFollowingScrollView` scrolls to the middle. *Retry banner* next: `.retryScheduled` sets `retryState` (`IDEAgentRetryState`: try, when the next attempt is due, which rate limit is used up), drawn with a live countdown ("Retrying in 42 s (try 2)", `TimelineView` once a second), Stop and **Retry Now** (`IDEAgentConversation.retryNow` → `AgentSession.retryNow()`, which ends the client's wait so the request is sent at once; the countdown then reads "Retrying now…"), replacing the grey status line. The countdown is the client's own wait, which already honours `Retry-After` (`RetryPolicy.delay`), so no reset headers are read. Any event other than `.retryScheduled`, `.turnRestarted` and `.rateLimit` ends it (the resent request answered, or the run ended), as do `isRunning` turning false and `reset()`. Retry Now covers the native chat's own turns (not an ACP agent, which retries by itself, nor a subagent's turns). Not built: a failure banner (the error row with Retry is already the last row above the composer). Tests: `IDEAgentBannerTests` (including a 429 with a 30 s `Retry-After` cut short by Retry Now); `IDEAIModeSnapshotTests.testTheDockedBanners` (`docked-banner-approval`, `docked-banner-retry`).

- **Agent: stashed drafts and tab tooltips** (`Composer/IDEAgentPromptStash.swift`, `IDEAgentStashButton`, `IDEAgentTabPreview`; plan: `docs/AGENT_UI_PLAN.md` items 7 and 8). *Stash*: ⌃S in the message field (`IDEAgentComposerKeyMap.stashDraft`; ⌥⌘S is Save All), or Stash Draft in the + button's context menu, puts the draft and its attached images aside and empties the field (`IDEAgentController.stashDraft`). Per project, shared by its windows and chats: `stash.json` beside `prompts.jsonl` (`promptStash()`, cached per root like the prompt history; in memory without a store), each draft's images as files in `stash-images/<id>/` (0600 in 0700 folders), newest first, at most 20 (the oldest dropped with its images). While any are stashed a tray button with a count sits beside +; its popover lists them (first line, age, image count): a click puts one back (`restoreStashed`), stashing what the field held first so nothing is lost, and × drops one. *Tab tooltips*: a chat tab's `.help` is `IDEAgentTabPreview.text`: title, what it is doing (the approval it waits for with its command, a question, a plan, a retry wait, "Working · <status>", "New reply", else "Last active …" from `IDEAgentConversation.lastActivity`, set when a run ends), the last reply cut to 3 lines, files changed and cost. A tab not read yet (`pendingLoadID`) is described from its `SessionSummary` (messages, updated, cost) and is never loaded for it. A native tooltip on purpose, not a hover popover, which would take the keyboard from the message field. Tests: `IDEAgentStashAndPreviewTests`, `IDEAgentComposerKeyMapTests`.

- **Agent: composer** (`Umbra/Sources/Umbra/Agent/Composer/`). The message field is an `NSTextView` (`IDEAgentComposerField`, because SwiftUI's `TextField` cannot see ↑/↓/Tab/Esc/⇧Tab or the caret): Return sends, ⇧↩ or ⌥↩ a newline, Esc closes the suggestion list and otherwise stops the run, ⇧Tab cycles the mode, and the text grows to `IDEAgentComposerField.maxTextHeight` (282 pt) before it scrolls. **The message box is one card, like Codex's** (`IDEAgentComposerCard`, shared by the agent panel in every placement and AI mode's Chat): the text on top, and inside the card below it a bar with + (attach) and how the agent may act on the left (permission chip, the ACP agent's mode and other options), the context ring and the model control on the right (`IDEACPModelPicker`, `IDEAIModelPicker` or the docked native `IDEAgentModelChip`), then the round send/stop button (`IDEAgentSendButton`); the card stops at about 340 pt, and a click on its empty space focuses the field. In AI mode's Code the project and branch chips sit on a tray behind the card's top edge (Codex's "This computer / Choose project" strip). The ACP model picker shows the price multiplier an agent sends on each model (`ACPChoiceRate`, from any `_meta.<vendor>.rateMultiplier`/`rateUnit`; Kiro's credits: auto 1×, claude-opus-5.5 2×, gpt-5.6-sol 4.4×, claude-haiku-5.5 0.06×). Look at it with `AI_MODE_PNG_DIR=/path swift test --package-path Umbra --filter "IDEAIModeSnapshotTests|IDEACPNativeProviderConversationTests"` (`docked-composer-*`, `acp-model-picker`). What a key does is a pure function (`IDEAgentComposerKeyMap`); what the text and caret ask for is another (`IDEAgentComposerTrigger.detect`: `/` as the message's first word, `@` at the start or after whitespace), tested without a view. `IDEAgentComposerState` holds the list's rows and highlight, `IDEAgentSuggestionList` draws it, and `IDEAgentController.suggestions(for:)` supplies the rows. `/commands` and `@` mentions are colored with attributes only; the model gets plain text. `@"path with spaces"` is the quoted form (`IDEAgentMentionToken`); files dropped on the field become mentions. Tests: `IDEAgentComposerFieldTests` hosts the field in a window.

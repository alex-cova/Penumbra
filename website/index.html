A fast code editor engine for macOS.

High-performance AppKit text engine with tree-sitter highlighting, multi-cursor editing, and a decoupled IDE intelligence layer.

View on GitHub Add to your app

Built with

Built for real editors

Forked from Runestone and extended for macOS. Ships as a Swift Package with a decoupled intelligence layer and Umbra, a reference editor app.

Text engine

AppKit-native editing with optional Metal rendering and piece-tree storage for large files.

  • Multi-cursor
  • Tree-sitter
  • Minimap
  • Folding

Editor Intelligence

Completion, hover, diagnostics, navigation, and rename through a provider-based platform.

  • LSP
  • Indexing
  • Command palette

Workbench

Split panes, tab groups, session restore, and native AppKit bridge views for IDE chrome.

Languages in Umbra

Bundled Tree-sitter packs plus Java intelligence: Gradle sync, completion, diagnostics, and run configs.

Umbra in action

Umbra is the Sublime Text-style editor in this repo: fast folder editing, Markdown preview, and Mermaid diagram rendering.

Get started

Add Penumbra to your Swift package, link the products you need, and drop a TextView into your app.

Package.swift 
dependencies: [
    .package(url: "https://github.com/alex-cova/Penumbra.git", branch: "main")
]

.target(
    name: "YourAppTarget",
    dependencies: [
        .product(name: "Penumbra", package: "Penumbra"),
        .product(name: "EditorIntelligence", package: "Penumbra"),
        .product(name: "EditorIntelligenceLSP", package: "Penumbra"),
        .product(name: "PenumbraLanguages", package: "Penumbra")
    ]
)
AppKit 
import AppKit
import Penumbra

textView.isLineWrappingEnabled = true
textView.showMinimap = true
textView.isLineFoldingEnabled = true
textView.isMetalRenderingEnabled = true

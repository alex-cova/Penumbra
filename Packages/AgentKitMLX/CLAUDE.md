# AgentKitMLX

Loaded when working under `Packages/AgentKitMLX`. Plan and decisions: `docs/AGENT_HARNESS_PLAN.md` (section 2). Only Umbra links this package; `AgentKit` does not.

- **Two targets.** `LocalModelStore` is Foundation and Security only (no MLX, builds fast, runs on any Mac): Hugging Face search (`HuggingFaceSearchEngine`), downloads (`LocalModelDownloader`: staging folder on the destination volume, manifest written last, folder renamed into place, pause/resume through `LocalModelDownloadCheckpoint`, every Hub path validated by `LocalModelPaths.safeDestination`), the installed-model catalog, `ChatTemplate` (does the template take tools?) and the Hugging Face token in the Keychain. `AgentKitMLX` depends on `AgentKit`, `LocalModelStore`, mlx-swift-lm and swift-transformers. Both were ported from Hextech (`../hextech/Hextech/Features/LocalModels`), keeping its tests; the manifest is still `hextech-model.json`, so a models folder can be shared with Hextech. Fixes made in one place are not in the other.
- **Metal library.** MLX throws a C++ exception, ending the process, if it finds no `default.metallib`/`mlx.metallib`. So `MLXMetalLibrary.install()` looks first (MLX's own places, plus the app's `Resources`, plus `LocalModelRuntime.extraMetalSearchRoots` for a test host) and tells MLX with `GPU.metallib`; `MLXAvailability.currentStatus()` reports `.missingMetalLibrary` instead of crashing. This mlx-swift version builds the library as `mlx-swift_Cmlx.bundle` with plain SwiftPM, so `swift build`/`swift run` work; `Scripts/build-app.sh` copies it to `Contents/Resources/mlx.metallib`. Under `swift test` the test host is Xcode's helper, so tests pass `MLXTestEnvironment.resourceRoots()`.
- **Loading.** Always `LLMModelFactory.shared.loadContainer(from:using:)` with `TokenizerBridgeLoader`; never `loadModelContainer(...)`, which finds the factory with `NSClassFromString` and can be stripped from a release link. One `LocalModelRuntime.shared` holds the loaded weights for the whole app; `acquire`/`release` keep the idle unload (default 30 min) from freeing a model mid-generation.
- **`MLXLLMClient`.** MLX 3.32's `ChatSession` keeps its own transcript, re-renders the whole conversation through the chat template each turn and reuses the longest matching token prefix of its KV cache (`GenerateCompletionInfo.cachedPromptTokenCount`). The client keeps the last turn's session and, when the new request is exactly what that session saw plus new items, sends only those; anything else (compaction, a model or tool change, a stopped or failed turn, a recovered tool call) builds a new session from the history with one full prefill. `TokenUsage.inputTokens` is the whole prompt and `cachedInputTokens` the part served from the cache.
- **Tool calls.** MLX parses them per model family (`ToolCallFormat`). A call it refuses (`rejectedToolCall`) is read again by `MLXToolCallRecovery` only for slips that stay unambiguous (doubled outer braces, a code fence) and only if it names a tool the request declared; otherwise the turn fails with the model's raw text in the message. A recovered call makes the next turn rebuild, because the session never saw the call. Call ids MLX does not supply are unique per call (a per-turn counter repeated ids across the conversation).
- **Thinking.** `<think>` blocks are split off by `LocalModelReasoningParser` with `allowsImplicitOpen: false`: a model whose template puts the opening tag in the prompt leaks its reasoning as answer text, which beats unsending bytes. `enable_thinking` is passed to the template from the request's reasoning setting.
- **Tests.** `swift test` runs the unit tests (Hextech's ported ones, stubbed-network downloader tests, conversation mapping, Metal library lookup, tool-call recovery). The real-model suite is opt-in and downloads a model once into `~/Library/Caches/AgentKitMLXTests`: `AGENTKIT_MLX_SMOKE=1 swift test --filter MLXSmokeTests` (default `mlx-community/Qwen2.5-3B-Instruct-4bit`; set `AGENTKIT_MLX_MODEL=mlx-community/Qwen2.5-7B-Instruct-4bit` for one whose tool calls MLX parses natively, which the cache-reuse test needs). `AGENTKIT_MLX_KERNEL_PROBE=1` runs one bare kernel to compare the library lookup with MLX's.
